## Download & Install

> Setup notes for **Grass Valley Edius X** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Grass Valley Edius X** from the Start menu

## What you can use it for

- Non-linear timeline video editing
- Multi-track audio and video compositing
- Transitions, titles, and effect filters
- Export H.264/H.265 for web and social
- Proxy editing for heavy 4K footage
